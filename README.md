📘 BookBazar – Buy & Sell Second-Hand Books

BookBazar is a full-stack web application that allows users to buy and sell second-hand books easily.
It is built to simulate a real-world e-commerce workflow and understand production-level deployment.

🛠️ Tech Stack

Frontend

React.js
Tailwind CSS

Backend

Node.js
Express.js

Database

MySQL (Railway)

Deployment

Frontend: Vercel
Backend: Render
Database: Railway

Other Tools

JWT Authentication
Multer (Image Upload)
Axios
✨ Features
🔐 User Authentication (Register/Login)
📚 Add & browse books
🖼️ Upload book images
🛒 Add to cart
💳 Order management system
📦 View orders
📱 Fully responsive UI
